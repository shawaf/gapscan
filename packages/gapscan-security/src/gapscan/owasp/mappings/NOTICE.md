# Attribution notice (CC BY-SA 4.0)

The files in this directory are **adapted material** derived from OWASP publications:

- `cwe_to_top10.csv`: the CWE lists in each category page of **OWASP Top 10:2025**
  (https://github.com/OWASP/Top10, `2025/docs/en`), reformatted into a table.
- `asvs_requirements.csv`: an unmodified copy of the **OWASP Application Security Verification
  Standard 5.0.0** CSV release asset (https://github.com/OWASP/ASVS).
- `cwe_to_asvs.csv`: CWE to ASVS 5.0.0 links computed from OWASP's archived v5.0.be CWE export and
  mapping files (https://github.com/OWASP/ASVS, `5.0/mappings`) and from the OpenCRE
  (https://opencre.org) ASVS/CWE listings. This is a modification of that material.
- `masvs_controls.csv`: the control ids, groups and one-line control titles of the **OWASP Mobile
  Application Security Verification Standard v2.1.0**, taken from its `OWASP_MASVS.cdx.json`
  release asset (https://github.com/OWASP/masvs), reformatted into a table.
- `versions.json`: exact source versions, commits and checksums.
